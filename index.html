# System / Site Type Transparency Level Methodology & How It Is Calculated Primary Focus
1 College Football Playoff (CFP) Human Committee Principles Published, Math N/A 13-member selection committee voting in secret balloting rounds evaluating head-to-head, SOS, and conference championships. Consensus voting without fixed formulas. Secret Consensus
2 Associated Press (AP) Top 25 Human Media Poll Public Voter Ballots 60+ sports journalists submit 1–25 ballots weekly (25 pts for #1 to 1 pt for #25). Fully public voter ballots published weekly on AP News. 25-to-1 Media Votes
3 US LBM Coaches Poll (USA Today) Human Coaches Poll Public Voter Ballots Active FBS head coaches submit weekly 1–25 ballots (25 pts to 1 pt). Published by USA Today with individual final ballots disclosed. Coaches Consensus
4 ESPN Football Power Index (FPI) Predictive Computer Concepts Explained, Code Proprietary Evaluates Expected Points Added (EPA) per play, returning production, recruiting ratings, and component efficiencies. Regression weights are proprietary. EPA / Drive Regressions
5 SP+ (Bill Connelly / ESPN) Predictive Computer Full Conceptual Breakdown Three pillars: Play-by-play Success Rate, Explosiveness (yards per successful play), and Finishing Drives. Integrates recruiting and returning production priors. Success & Explosiveness
6 Sagarin Ratings (Jeff Sagarin) Predictive & Elo Fully Explained Principles Linear algebra & network theory modeling with diminishing-returns point margins. Publishes Elo-Chess vs Predictor ratings and exact home-field adjustments. Diminishing Margin SAM
7 TeamRankings Predictive Ratings Predictive Computer Inputs & Mechanics Published Point differential adjusted for opponent strength, venue location, and game state. Rating difference represents expected neutral field point spread. Vegas Neutral Spread
8 Colley’s Bias-Free Matrix Résumé Computer Fully Open Source Math Solves linear equation system (r = M⁻¹ b). Completely ignores point margins, assessing purely wins, losses, and opponent win percentages. Pure Matrix W-L (r=M⁻¹b)
9 CFB Graphs / CollegeFootballData (PPA) Analytical Metric Site Open Methodology & Public API Uses Predicted Points Added (PPA) per play based on down, distance, and field position on an open-source model with full public API availability. Per-Play Net PPA
10 Massey Ratings (Kenneth Massey) Composite / Computer Mathematical Formulation Published Least-squares linear model balancing scoring differential and game outcomes against strength of schedule. Also hosts the Massey Composite of 100+ computer ratings. Least-Squares Composite
